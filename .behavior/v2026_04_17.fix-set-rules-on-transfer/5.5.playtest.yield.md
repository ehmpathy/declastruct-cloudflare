# playtest: declarative cloudflare domain redirect rules

## prerequisites

- node.js and pnpm installed
- cloudflare credentials unlocked: `rhx keyrack unlock --owner ehmpath --env test`
- project built: `npm run build`

## sandbox

all file operations target `.temp/` directory.

## part 1: build and type check

### step 1.1: build the package

```bash
npm run build
```

**pass if:** exit 0, no errors
**fail if:** exit non-zero or type errors

**proof:** covered by `rhx git.repo.test --what types` in CI

### step 1.2: verify exports

```bash
node -e "const m = require('./dist/contract/sdks'); console.log(Object.keys(m).sort().join('\n'))"
```

**pass if:** output includes:
- `DeclaredCloudflareDomainRuleRedirect`
- `DeclaredCloudflareDomainRuleRedirectSpec`
- `RULE_REDIRECT_SPEC_HTTP_TO_HTTPS`
- `RULE_REDIRECT_SPEC_ROOT_TO_WWW`

**fail if:** any of the above are absent

**proof:** covered by `index.integration.test.ts` snapshot

## part 2: verify preset contents

### step 2.1: inspect HTTP to HTTPS preset

```bash
node -e "
const { RULE_REDIRECT_SPEC_HTTP_TO_HTTPS } = require('./dist/contract/sdks');
console.log(JSON.stringify(RULE_REDIRECT_SPEC_HTTP_TO_HTTPS, null, 2));
"
```

**pass if:** output shows:
- `expression` contains `(not ssl)`
- `action.statusCode` is `301`
- `action.target.queryString` is `"preserve"`

**proof:** covered by `DeclaredCloudflareDomainRuleRedirect.test.ts` lines 10-20


**pass if:** output shows:
- `expression` contains `(not starts_with(http.host, "www."))`
- `action.statusCode` is `301`
- `action.target.queryString` is `"preserve"`

**fail if:** structure differs from expected

**proof:** covered by `DeclaredCloudflareDomainRuleRedirect.test.ts` lines 22-33

## part 4: dogfood against test domains

this section verifies redirect rules work on real domains (without transfer).

### step 4.1: unlock credentials

```bash
rhx keyrack unlock --owner ehmpath --env test
```

**pass if:** credentials unlocked

### step 4.2: run plan against transfer-in resources

```bash
ENV=test npx declastruct plan \
  --wish provision/domains/resources.ts \
  --into .temp/domains-plan.json
```

**pass if:** plan shows redirect rules for each domain:
- `redirect-http-to-https` (CREATE or KEEP)
- `redirect-root-to-www` (CREATE or KEEP)

**fail if:** plan errors or redirect rules absent

**proof:** covered by `declastruct.acceptance.test.ts`

### step 4.3: apply redirect rules

```bash
ENV=test npx declastruct apply --plan .temp/domains-plan.json
```

**pass if:** apply completes, rules created/kept in cloudflare

**fail if:** apply errors

### step 4.4: verify idempotency

```bash
# regenerate plan
ENV=test npx declastruct plan \
  --wish provision/domains/resources.ts \
  --into .temp/domains-plan2.json

# check for drift
cat .temp/domains-plan2.json | jq '[.changes[] | select(.forResource.class == "DeclaredCloudflareDomainRuleRedirect")] | map(.action)'
```

**pass if:** all redirect rule actions are `KEEP`

**fail if:** any action is `CREATE` or `UPDATE` (drift detected)

### step 4.5: verify in cloudflare dashboard

1. go to https://dash.cloudflare.com
2. select zone (e.g., `sunshineoceansurferturtles.com`)
3. navigate to Rules > Redirect Rules

**pass if:**
- rule `redirect-http-to-https` exists with expression `(not ssl)`
- rule `redirect-root-to-www` exists with expression `(not starts_with(http.host, "www."))`

**fail if:** rules absent or expressions wrong

### step 4.6: verify redirect behavior (optional)

```bash
curl -I http://sunshineoceansurferturtles.com 2>/dev/null | head -3
```

**pass if:** HTTP 301, Location header points to https://

**fail if:** no redirect or wrong status code

## pass/fail criteria

### overall pass
- all steps in parts 1-3 pass
- part 4 passes if test zone is available

### overall fail
- any step in parts 1-3 fails
- type errors
- export verification fails
- acceptance tests fail
