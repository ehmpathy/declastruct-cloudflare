## pattern.3: expandZoneRef utility [REUSE]

### source

```typescript
// src/domain.operations/domainDnsRecord/expandZoneRef.ts:12-38
export const expandZoneRef = async (
  zoneRef: Ref<typeof DeclaredCloudflareDomainZone>,
  context: ContextCloudflareApi,
): Promise<{ id: string; name: string }> => {
  // if have id, lookup zone to get name
  if ('id' in zoneRef && zoneRef.id) {
    const zone = await getOneDomainZone({ by: { primary: { id: zoneRef.id } } }, context);
    if (!zone) BadRequestError.throw('zone not found for ref', { zoneRef });
    return { id: zone.id, name: zone.name };
  }
  // if have name, lookup zone to get id
  if ('name' in zoneRef && zoneRef.name) {
    const zone = await getOneDomainZone({ by: { unique: { name: zoneRef.name } } }, context);
    if (!zone) BadRequestError.throw('zone not found for ref', { zoneRef });
    return { id: zone.id, name: zone.name };
  }
  BadRequestError.throw('invalid zone ref', { zoneRef });
};
```

### relevance

redirect rules need zone ID for API calls. same utility can be reused directly — no modification needed.

### relevance

redirect rules will follow same findsert/upsert semantics:
- findsert: return extant if found, create if absent

## pattern.7: castInto* transformer [REUSE]

### source

```typescript
// src/domain.operations/domainDnsRecord/castIntoDeclaredCloudflareDomainDnsRecord.ts:76-105
export const castIntoDeclaredCloudflareDomainDnsRecord = (
  rawInput: unknown,
  zoneRef: { name: string },
): HasReadonly<typeof DeclaredCloudflareDomainDnsRecord> => {
  const input = rawInput as CloudflareDnsRecordShape;
  return assure(
    DeclaredCloudflareDomainDnsRecord.as({
      id: assure(input.id, isPresent),
      zone: zoneRef,
      name: assure(input.name, isPresent),
      // ... snake_case to camelCase transform
      createdOn: input.created_on,
      modifiedOn: input.modified_on,
    }),
    hasReadonly({ of: DeclaredCloudflareDomainDnsRecord }),
  );
};
```

### relevance

redirect rules need same pattern:
- transform cloudflare's snake_case to our camelCase
- transform `description` to `slug`
- transform `preserve_query_string` to `queryString: 'preserve' | 'ignore'`
- assure readonly fields via `hasReadonly`

## cloudflare SDK methods

redirect rules use different SDK methods than DNS records:

| resource | SDK method |
|----------|------------|
| DNS records | `client.dns.records.*` |
| redirect rules | `client.rulesets.*` |

specifically:
- `client.rulesets.phases.get(phase, { zone_id })` — get phase entrypoint ruleset
- `client.rulesets.update(ruleset_id, { zone_id, rules })` — PUT entire ruleset
