# experience reproductions: declarative cloudflare redirect rules

## experience reproductions

| experience | entry point | user actions | expected outcome | test type |
|------------|-------------|--------------|------------------|-----------|
| add redirect rules to domains | resources file | declare rules, run plan, run apply | rules created in cloudflare | acceptance |
| use HTTP→HTTPS preset | resources file | use RULE_REDIRECT_SPEC_HTTP_TO_HTTPS | http requests redirect to https | integration |
| use root→www preset | resources file | use RULE_REDIRECT_SPEC_ROOT_TO_WWW | apex requests redirect to www | integration |
| custom redirect rule | resources file | create custom spec with expression | custom redirect works | integration |
| idempotent re-apply | declastruct apply | run apply twice | no changes on second run | acceptance |

## journey test sketches

### journey 1: add redirect rules via declastruct

#### step table

| step | action | user sees |
|------|--------|-----------|
| t0 | before any changes | zone exists, no redirect rules |
| t1 | run declastruct plan | plan shows +2 rules (HTTP→HTTPS, root→www) |
| t2 | run declastruct apply | rules created, apply completes |
| t3 | run declastruct plan again | plan shows 0 changes (idempotent) |

#### t0: before state

```typescript
// resources file
const zone = new DeclaredCloudflareDomainZone({ name: 'example.com', type: 'full' });

// no redirect rules declared yet
```

#### t1: plan shows rules to create (snapshot target)

```bash
$ npx declastruct plan --wish resources.ts --into plan.json

🐢 heres the wave...

🐚 declastruct plan
   └─ changes
      └─ example.com
         ├─ + DeclaredCloudflareDomainRuleRedirect:force-https
         └─ + DeclaredCloudflareDomainRuleRedirect:apex-to-www
```

```json
// plan.json (snapshot)
{
  "changes": [
    {
      "type": "DeclaredCloudflareDomainRuleRedirect",
      "decision": "CREATE",
      "ref": { "zone": { "name": "example.com" }, "slug": "force-https" }
    },
    {
      "type": "DeclaredCloudflareDomainRuleRedirect",
      "decision": "CREATE",
      "ref": { "zone": { "name": "example.com" }, "slug": "apex-to-www" }

```

#### t2: apply creates rules (snapshot target)

```bash
$ npx declastruct apply --plan plan.json

🐢 cowabunga!

🐚 declastruct apply
   └─ applied
      └─ example.com
         ├─ ✔ DeclaredCloudflareDomainRuleRedirect:force-https
         └─ ✔ DeclaredCloudflareDomainRuleRedirect:apex-to-www
```

#### t3: second plan shows no changes (idempotent)

```bash
$ npx declastruct plan --wish resources.ts --into plan.json

🐢 righteous!

🐚 declastruct plan
   └─ changes: none
```

### journey 2: redirect rules with presets

#### step table

| step | action | user sees |
|------|--------|-----------|
| t0 | declare zone with preset rules | resources file with presets |
| t1 | run plan | shows rules to create |
| t2 | run apply | rules created |
| t3 | curl http://example.com | 301 redirect to https://example.com |
| t4 | curl https://example.com | 301 redirect to https://www.example.com |

#### t0: resources file with presets (snapshot target)

```typescript
import { refByUnique } from 'domain-objects';
import {
  DeclaredCloudflareDomainZone,
  DeclaredCloudflareDomainRuleRedirect,
  RULE_REDIRECT_SPEC_HTTP_TO_HTTPS,
  RULE_REDIRECT_SPEC_ROOT_TO_WWW,
} from 'declastruct-cloudflare';

export const getResources = async () => {
  const zone = new DeclaredCloudflareDomainZone({ name: 'example.com', type: 'full' });

  return [
    zone,
    new DeclaredCloudflareDomainRuleRedirect({
      zone: refByUnique(zone),
      slug: 'force-https',
      spec: RULE_REDIRECT_SPEC_HTTP_TO_HTTPS,
    }),
    new DeclaredCloudflareDomainRuleRedirect({
      zone: refByUnique(zone),
      slug: 'apex-to-www',
      spec: RULE_REDIRECT_SPEC_ROOT_TO_WWW,
    }),
  ];
};
```

#### t3: HTTP→HTTPS redirect verification

```bash
$ curl -I http://example.com
HTTP/1.1 301 Moved Permanently
Location: https://example.com/
```

#### t4: root→www redirect verification

```bash
$ curl -I https://example.com
HTTP/1.1 301 Moved Permanently
Location: https://www.example.com/
```

## reproduction feasibility

### available test utilities

- `getSampleCloudflareApiContext()` — creates live API context
- `given/when/then/useBeforeAll` — BDD test structure from test-fns
- `getAllDomainZones()` — fetch zones for test setup
- cloudflare demo account credentials via keyrack

### required setup

- CLOUDFLARE_API_TOKEN env var
- CLOUDFLARE_ACCOUNT_ID env var
- at least one zone in account (for integration tests)

### test sketch

```typescript
// domainRuleRedirect.play.integration.test.ts
describe('redirect rule journey', () => {
  given('[case1] zone with no redirect rules', () => {
    const scene = useBeforeAll(async () => {
      const zones = await getAllDomainZones(getContext());
      return { zone: zones[0] };
    });

    when('[t0] before any changes', () => {
      then('no redirect rules exist', async () => {
        const rules = await getAllDomainRuleRedirects({ zone: scene.zone }, getContext());
        expect(rules).toEqual([]);
      });
    });

    when('[t1] setDomainRuleRedirect with HTTP_TO_HTTPS preset', () => {
      const rule = useThen('rule is created', async () => {
        return setDomainRuleRedirect({
          findsert: {
            zone: { name: scene.zone.name },
            slug: 'test-https-redirect',
            spec: RULE_REDIRECT_SPEC_HTTP_TO_HTTPS,
          },
        }, getContext());
      });

      then('rule has expected properties', () => {
        expect(rule.id).toBeDefined();
        expect(rule.slug).toEqual('test-https-redirect');
      });
    });
  });
});
```
