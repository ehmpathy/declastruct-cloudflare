# evaluation: declarative cloudflare domain redirect rules

reference blueprint: `.behavior/v2026_04_17.fix-set-rules-on-transfer/3.3.1.blueprint.product.yield.md`

---

## summary (as implemented)

add declarative control over cloudflare domain redirect rules via:
- `DeclaredCloudflareDomainRuleRedirect` domain entity
- `DeclaredCloudflareDomainRuleRedirectSpec` spec literal
- preset specs: `RULE_REDIRECT_SPEC_HTTP_TO_HTTPS`, `RULE_REDIRECT_SPEC_ROOT_TO_WWW`
- get/set/del operations with findsert/upsert semantics
- DAO integration for declastruct provider
